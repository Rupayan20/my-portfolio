# **My Portfolio Website**

Welcome to the repository for my personal portfolio website! You can view the live version of my portfolio [here](https://myself-rupayandutta.netlify.app/).

## **Overview**

This portfolio showcases my projects, skills, and experiences as a developer. It's designed to provide a brief introduction about me, highlight my professional journey, and serve as a point of contact for potential collaborators or employers.

## **Features**

- **Home Page**: Introduction and a brief about me.
- **Work Experience**: Details of my professional experience, including roles and responsibilities.
- **Projects**: Showcase of my projects, both personal and professional.
- **Skills**: Technical skills and competencies.
- **Education**: Academic background.
- **Contact**: Easy ways to get in touch with me.

## **Technologies Used**

- **Frontend**: HTML, CSS, JavaScript, React
- **Deployment**: Netlify

## **Getting Started**

To run this project locally:

1. **Clone the repository:**

    ```bash
    git clone https://github.com/Rupayan20/my-portfolio.git
    ```

2. **Navigate to the project directory:**

    ```bash
    cd my-portfolio
    ```

3. **Install dependencies:**

    ```bash
    npm install
    ```

4. **Run the application:**

    ```bash
    npm start
    ```

   This will start the development server and open the website in your default browser.
